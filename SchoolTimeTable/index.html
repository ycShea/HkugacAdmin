Teacher Timetable PDF → Excel

Upload the aSc teacher-timetable PDF and download (1) one timetable sheet per teacher and (2) a database-style Excel file (Teacher | Day | Period | Class | Venue | Co-teaching | Lesson/Meeting/Support). Teacher names are read from the PDF itself. Everything runs in your browser.

1. Choose the PDF

2. Teacher list (CSV)

One list of teacher initials, names and departments (Initial,Name,Department), shared by the Teacher and Class tabs. It is created automatically when you read a Teacher PDF and is used to fill the “Teacher Name” column in the class database. You can also choose your own CSV. When a Teacher PDF is read and a list is already loaded, the PDF is checked against the list.

Free lesson attendance

Built from the Class PDF you read. One row per class, day and period (Subject | Day | Period), where Subject is the class and the subject, for example S4A-MA. For S4–S6 the electives are shown as E1, E2 or E3. Everything runs in your browser.

1. Levels

S4–S6 are ticked by default. S1–S3 subjects are shown as printed (for example S1H-ICT).

2. Map the electives

These classes have no E1/E2/E3 block lessons, so the number cannot be worked out from the timetable. Choose the number for each subject. The defaults are PHY and EC/PHY → E1, CHEM → E2, BIO → E3. A class that has two blocks gets the missing number automatically.
